# 阅读画像生成器

在 personal-librarian 仓库根目录下工作，产出两个文件，供网站「阅读画像」页面（`site/`）展示：

| 文件 | 内容 | 来源 |
| ---- | ---- | ---- |
| `profile/reading-stats.json` | 微信读书阅读统计快照（时长、天数、偏好分类、阅读时段、读得最久的书、每本书开始/读完/最近阅读时间） | 本 skill 自带脚本，从微信读书 API 拉取 |
| `profile/阅读画像.md` | AI 撰写的阅读画像（第一人称「我」） | agent 阅读全部笔记与心得后撰写，**用户确认后定稿** |

## 工作流程

### 第一步：刷新统计快照

确认已设置 `WEREAD_API_KEY`（未设置时提示用户 `export WEREAD_API_KEY=<你的apikey>`），在仓库根目录运行：

```bash
python3 <本 skill 目录>/scripts/fetch_reading_stats.py
```

脚本只写入汇总数据；排行和阅读时间只保留 `notes/`、`reflections/` 中存在的书。若脚本提示某些书没有阅读时间（例如纸质书），询问用户读完的日期（记不清可以只给年月），写入 `reflections/<书名>/meta.json` 的 `"readAt": "YYYY-MM-DD"`（或 `"YYYY-MM"`）字段。

用户只要求"刷新阅读数据"时，到这里即可结束。

### 第二步：通读素材

- `profile/reading-stats.json`：偏好分类、逐年时长、读得最久的书、每本书最近阅读时间（`meta.json` 的 `readAt` 优先），以及开始和读完时间。
- `reflections/*/读书心得.md`：重点读「三、心得体会」和每段摘录后的个人解读，这是用户自己的观点与经历。
- `notes/*/划线与想法.md`：划线反映关注点；`**想法**：` 开头的段落是用户自己的话。
- 已有的 `profile/阅读画像.md`（如存在）：更新时在原稿基础上修订，保留用户确认过的表述。

### 第三步：分析并起草

按「输出格式」起草全部内容，要求：

1. **阅读人格**：一个 4–10 字的称号 + 一段 2–4 句的第一人称画像，概括我读什么、为什么读、读书给我带来了什么。
2. **关键词**：10–20 个，权重 1–5（5 最重要），覆盖主题、价值观和阅读习惯，不要只罗列书籍分类。
3. **核心关注主题**：3–5 个。每个主题一段分析（结合具体的书和我的想法，说明我关注它的原因和收获），并列出 2–5 本代表书籍。代表书籍必须使用 `notes/`、`reflections/` 中的目录名，写作 `《书名》`。
4. **思想变化轨迹**：按年份（读完的书以读完时间归年，在读的书以最近阅读时间归年，与网站「阅读足迹」一致）各写一段，说明这一年读了哪类书、关注点和想法如何变化、与上一年相比有什么转变。只写有书的年份。
5. **金句**：「书中原文」与「我的感悟」各 4–8 条，意思不重复。
   - 书中原文：从划线中挑最能代表我价值观、最触动我的句子，逐字摘录，不改写。
   - 我的感悟：只能取自我自己写的文字（`**想法**：` 段落、心得中的个人解读与心得体会），可删减为独立成立的一两句话，但不得改变原意，不得编造。
   - 每条以 `——《书名》` 注明出处。

**真实性原则**：画像中的每一个判断都要能在素材中找到依据，不编造经历、情绪和观点；没有依据的推测不要写。

### 第四步：与用户确认（必需）

**不要直接写入文件。** 先把完整草稿展示给用户，并一次性列出拿不准的地方，引导用户给出真实想法，例如：

- 人格称号是否贴切？有没有更想要的说法？
- 某一年关注点发生转变的真实原因是什么（换工作、读研、身体原因……）？
- 哪些金句最能代表自己？有没有想替换或删掉的？

根据用户反馈修改，直到用户确认，再写入 `profile/阅读画像.md`。

### 第五步：自检

- [ ] `profile/reading-stats.json` 已刷新，快照日期为今天
- [ ] 画像全文使用第一人称「我」，不使用性别代词指代用户
- [ ] 标题层级、字段写法与「输出格式」完全一致（网站按此格式解析）
- [ ] 代表书籍与金句出处都是仓库中存在的书名
- [ ] 书中原文逐字摘录；我的感悟出自用户本人文字
- [ ] 文末已附生成声明

## 输出格式

`profile/阅读画像.md` 必须严格使用以下结构（二级、三级标题文字固定，网站据此解析）：

```markdown
# 我的阅读画像

> 更新日期：YYYY-MM-DD

## 阅读人格

**称号**：<4–10 字的称号>

<2–4 句第一人称画像>

## 关键词

- <关键词>（<权重 1–5>）
- <关键词>（<权重 1–5>）

## 核心关注主题

### <主题名>

<一段分析>

代表书籍：《书名》《书名》

## 思想变化轨迹

### <YYYY> 年

<一段总结>

## 金句

### 书中原文

> <原文>
>
> ——《书名》

> <原文>
>
> ——《书名》

### 我的感悟

> <我的话>
>
> ——《书名》

---

> 本文由 Claude Code 调用 [generate-reading-profile](https://github.com/cedar-ai-project/personal-librarian/tree/main/skills/generate-reading-profile) skill 自动生成。
```

格式要点：

- 每条金句是一个独立的 `>` 引用块，引用块之间空一行；出处单独一行，以 `——《书名》` 开头。
- 关键词权重使用全角括号，如 `- 自我认知（5）`。
- 思想变化轨迹的标题写作 `### 2024 年`，按年份升序排列。
- 遵循 AGENTS.md：中文 Markdown。
